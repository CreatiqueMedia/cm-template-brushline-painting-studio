# Brushline Painting Studio

> Fine-art painting website template for commissions, collections, and exhibit launches.

## Live Demo

See it in action: [https://creatiquemedia.com/templates/brushline-painting-studio/demo](https://creatiquemedia.com/templates/brushline-painting-studio/demo)

## Who It Is For

Painters, portrait artists, muralists, and gallery-focused creators.

An artist website template for painters with commission booking, original collection pages, an exhibit calendar, and print shop conversion paths.

## What's Included

**Key sections and features:**

- Commission booking path with style and budget matching
- Original work showcase and sold-archive credibility blocks
- Exhibition and event calendar sections
- Print shop path for art-product revenue

**Additional features:**

- Commission funnel with scope, size, and medium selection
- Collection pages with current originals, sold works, and waiting-list prompts
- Exhibit calendar with shows, open studios, and RSVP sections
- Print commerce paths with edition and shipping notes
- Client proof: collector reviews, press mentions, process highlights
- Studio booking forms for consultations and mural scoping

**Demo page blocks:** Collection Drop Grid, Commission Matcher, Exhibit Timeline.

## Design & Tech Highlights

Built with Next.js, React, TypeScript, and Tailwind CSS, with Stripe and PWA support listed in the template stack.
